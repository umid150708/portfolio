Projects

Selectedwork

01Live · solo project

Fursatly

An AI platform that finds scholarships, programmes and opportunities for Uzbek students and keeps itself up to date.

Next.js 15React 19SupabaseVercel cronGeminiGroqPuppeteer
fursatly.uzSource on GitHub

How it works

  1. Collect. Scheduled jobs scrape public channels and pages for new posts.
  2. Filter. Paid promotions and duplicates are dropped before a model sees them.
  3. Extract. An LLM (Gemini, Groq as fallback) turns each post into title, deadline and link.
  4. Enrich and store. The official source and a summary are added, then saved to Supabase.
  5. Publish. Site with deadline countdowns, an AI mentor chat and a Telegram channel.
  6. Monitor. A health check tests keys, database and data freshness every day.
02Live · team project

Obuna+

A Telegram subscription platform for paid channels in Uzbekistan. Subscribers pay with Payme or Paylov, access renews automatically, and creators get statistics and payouts.

NestJSNext.jsTelegram Mini AppPostgreSQLPrismaPaymePaylov

My part: I am one of the developers on a team. I work on creator statistics, week-based billing periods, subscriber profiles, payment simulation for testing and secure Mini App login.

obunaplus.uz@obunaplusbot

How it works

  1. Choose. A subscriber opens the Telegram Mini App and picks a creator's tariff.
  2. Pay. Payment goes through Payme or Paylov, with fiscal receipts.
  3. Grant. The backend activates the subscription and the bot gives channel access.
  4. Renew. Cron jobs charge the saved card each period and remove access when it lapses.
  5. Report. Creators see subscribers and statistics; admins run payouts in a dashboard.
03Live

School №16 website and admin panel

The website of a school in Jizzakh, with an admin panel that its staff use to keep timetables, classes and news current.

ReactViteSupabasePostgres RLSEdge functionsPython

My part: the admin panel, access control, data import and SEO setup, built on top of the school's original site.

16-maktab-shr.uz

How it works

  1. Import. The school system's spreadsheet exports are parsed and loaded into Supabase, with a dry run first.
  2. Serve. A React and Vite site shows timetables, news and a contact form.
  3. Manage. Staff sign in at one of three levels (owner, school admin, staff); Postgres row-level security enforces it.
  4. Track. Changes go to an activity log that feeds a notification bell.
04Personal learning tool

Harf

Audio flashcards for learning the Arabic alphabet, built for myself when I started learning Arabic.

JavaScriptPythonGoogle Cloud TTSSpaced repetition

How it works

  1. Define. 28 letters with tips and Uzbek example words live in one data file.
  2. Generate. A build script creates every audio clip with Google Cloud text-to-speech.
  3. Practise. Four modes: listen, read, pairs of similar letters, and an alphabet reference.
  4. Remember. Each letter has a strength from 0 to 5, and new groups of seven unlock as you improve.
